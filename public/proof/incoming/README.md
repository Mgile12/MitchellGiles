# Incoming proof screenshots

Drop new heatmaps and Business Profile performance screenshots here (PNG or JPG, any size).
Claude crops the business names out, converts them, names them like the existing files in
`public/proof/`, and wires them into the proof page, the GBP page and the case studies.

Useful to note in the filename if you can: what it is and the dates, e.g.
`heatmap-plumber-before-2026-08-02.png`, `gbp-calls-may-sep-2026.png`.
